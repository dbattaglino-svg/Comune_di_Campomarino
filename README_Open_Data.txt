# Dataset Open Data - Comune di Campomarino (CB)

## Descrizione
Questo dataset contiene informazioni relative a:
- Popolazione residente di origine non italiana

I dati sono aggregati e coprono il periodo dal **2023 al 2025**.

## Colonne del Dataset
- **Anno**: Anno di riferimento.
- **tot_comun**: Totale Residenti comunitari dell'anno di riferimento.
- **tot_extra**: Totale Residenti extracomunitari dell'anno di riferimento.
- **m_comun**: Totale Residenti comunitari "Maschi".
- **f_comun**: Totale Residenti comunitari "Femmine".
- **m_extra**: Totale Residenti extracomunitari "Maschi".
- **f_extra**: Totale Residenti extracomunitari "Femmine".
- **com_0/18**: Totale Residenti comunitari tra 0 e 18 anni.
- **com_>18**: Totale Residenti comunitari oltre 18 anni.
- **extra_0/18**: Totale Residenti extracomunitari tra 0 e 18 anni.
- **extra_>18**: Totale Residenti extracomunitari oltre 18 anni.
